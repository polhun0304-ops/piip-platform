# 탐정 가이드 (Detective Guide)

목적: 탐정(수사관) 역할로 서비스에 접근할 때의 주요 워크플로우, 보안 권장사항, UI/사용성 팁을 제공합니다.

## 1. 로그인 및 계정

- 탐정 계정은 관리자에 의해 발급되거나, 자체 등록 후 검수 과정을 거칩니다.
- 로그인 후 토큰은 로컬 스토리지(`piip_token`)에 저장되며, Socket.IO 핸드셰이크 등에서 사용됩니다.

## 2. 대시보드 주요 흐름

- **나의 할당 사건 목록**: 할당된 사건만 표시됩니다.
- **사건 상세 보기**: 피의자·증거·할당 로그 확인.
- **증거 업로드**: 영상/음성/이미지 등 파일 업로드 가능(권한 있는 사건에 한함).
- **AI 증거 분석**: 업로드 후 자동으로 분석 작업이 시작됩니다(엔큐). 분석 결과는 탐정/관리자에게 전체 보기로 제공됩니다.

## 3. 보안 관련 유의사항 (탐정용)

- 개인 토큰을 타인과 공유하지 마세요.
- 수집한 증거는 법적 절차를 준수하여 보관·전달하세요.
- 업로드 파일은 민감정보(주민등록번호 등)를 포함하지 않도록 주의하세요.

## 4. 긴급 대응 절차

- 권한 없이 접근 가능한 자료를 발견하면 즉시 관리자에게 보고하세요.
- 의심스러운 파일 업로드(확장자 위조 등)는 보관 후 관리자에 통보하세요.

## 5. 운영 팁

- 사건의 증거는 사건별 폴더를 사용해 관리하세요.
- AI 분석 결과는 조사 보조용이며, 법적 효력은 검토가 필요합니다.
