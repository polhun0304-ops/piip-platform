# Consultation Copy Library (KO/EN)

다음 카피는 화면/이메일/SMS에 바로 적용 가능한 문안입니다. 변수는 {{like_this}} 형태로 표시합니다.

---

## 1) CTA/배너/모달 카피 [KO]

- 글로벌 CTA 버튼:
  - "전문가와 15분 무료 상담"
  - 보조 링크: "건너뛰고 계속"
- 강한 권유 배너(소프트 게이팅 시):
  - 헤드라인: "이 사건은 상담을 권장드려요"
  - 본문: "민감한 사안/고가 견적/불확실성이 감지되었습니다. 15분 상담으로 정확히 확인해보세요."
  - 버튼: "무료 상담 예약하기" / 링크: "지금은 건너뛰기"
- 모달 - 타입 선택:
  - 제목: "상담 옵션 선택"
  - 옵션 A: "무료 15분 상담"
  - 옵션 B: "유료 30분 딥다이브 — 49,000원(프로젝트 진행 시 100% 크레딧)"
- 모달 - 시간 선택:
  - 제목: "시간을 선택하세요"
  - 타임존 안내: "시간대: {{timezone}}"
- 모달 - 동의 체크:
  - 체크박스1: "이 상담은 법률 자문이 아닙니다"
  - 체크박스2: "동의 없이 녹취/녹화되지 않습니다"
  - 체크박스3: "개인정보 처리방침을 확인했습니다"
- 확인 스크린:
  - 제목: "예약이 완료되었어요"
  - 본문: "{{datetime}}에 {{channel}}로 연결됩니다. 이메일과 문자로 링크를 보내드릴게요."

## 1) CTA/Banner/Modal [EN]

- Global CTA:
  - "15-min Free Consultation"
  - Secondary: "Continue without consultation"
- Strong Recommendation Banner:
  - Headline: "We recommend a consultation"
  - Body: "We detected sensitivity/high quote/uncertainty. A 15-min call helps ensure fit."
  - Button: "Book Free Call" / Link: "Skip for now"
- Modal - Type:
  - Title: "Choose an option"
  - A: "Free 15-min consultation"
  - B: "Paid 30-min deep-dive — KRW 49,000 (100% credited if you proceed)"
- Modal - Time:
  - Title: "Pick a time"
  - Timezone note: "Timezone: {{timezone}}"
- Modal - Consent:
  - CB1: "This is not legal advice"
  - CB2: "No recording without consent"
  - CB3: "I have read the privacy policy"
- Confirmation:
  - Title: "You're booked"
  - Body: "Join via {{channel}} at {{datetime}}. We'll send Email/SMS links."
