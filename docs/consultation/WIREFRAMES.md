````text
# Consultation Wireframes (ASCII)

본 문서는 핵심 화면의 와이어프레임(텍스트 기반)을 제공합니다. 실제 UI 구현 시 컴포넌트/브랜드 가이드를 반영하세요.

---

## A. 인테이크 요약 화면 + 선택형 CTA

```text
+--------------------------------------------------------------+
| [AI 요약]                                                     |
| - 핵심 포인트1                                                |
| - 핵심 포인트2                                                |
| - 리스크/확신도: 중(0.55)  [권장 배지: 상담 권장]            |
|                                                              |
|  [전문가와 15분 무료 상담]   (링크) 건너뛰고 계속 →          |
+--------------------------------------------------------------+
````

강한 권유 조건일 때 상단 배너 추가:

```text
[이 사건은 상담을 권장드려요] 민감/고가/불확실 신호 감지됨. → 무료 상담 예약
```

## B. 견적 화면 사이드바 CTA


## C. 상담 예약 모달(1) — 옵션 선택

```text
+---------------- 상담 옵션 선택 ----------------+
|  ○ 무료 15분 상담                              |
|  ○ 유료 30분 딥다이브 — 49,000원 (100% 크레딧) |
|                                                |
| [다음]                              [취소]     |
+-----------------------------------------------+
```

## D. 상담 예약 모달(2) — 시간 선택

```text
+---------------- 시간 선택 (TZ: KST) -----------+
|  10:00  10:30  11:00  11:30  13:00  13:30 ...  |
|                                                |
| [이전]                            [다음]       |
+-----------------------------------------------+
```

## E. 상담 예약 모달(3) — 동의/확인

```text
+---------------- 동의/확인 ---------------------+
|  [ ] 법률 자문이 아님                          |
|  [ ] 동의 없는 녹취/녹화 없음                  |
|  [ ] 개인정보 처리방침 확인                    |
|                                                |
|  일정: 2025-11-07 13:30 (KST) — 화상           |
|                                                |
| [예약하기]                         [이전]      |
+-----------------------------------------------+
```

```text
|  • 캘린더 추가(ICS)                            |

```

```text
+-----------------------------------------------+
```

## I. 탐정(모바일) 일정 확인

```text
+---------------- Detective Mobile --------------+
| 오늘: 10:30 / 13:00 / 16:00                    |
| 다음: 내일 11:30                               |
|  [상세]  접속링크  의뢰 요약  체크리스트       |
+-----------------------------------------------+
```

---

### 구현 메모

- 항상 "건너뛰고 계속" 제공.
- 강한 권유는 배너/모달로 시그널링(조건 기반).
- 리마인더: T-24h/T-2h Email+SMS. ICS 다운로드 버튼.
- 결제 완료 페이지에서 킥오프 콜 선택 제공.
  | 탐정B [10:30][13:00] ... |
  | 필터: 카테고리/우선순위/타임존 |
  | 충돌 감지/이중예약 방지 ON |
  +-----------------------------------------------+
