목적: 탐정·민간조사 활동을 온라인/모바일로 통합하여 의뢰 접수 → 조사 수행 → 증거관리 → 보고·결제까지 전 과정을 안전하고 법적 준수를 보장하며 자동화하는 플랫폼 설계. 핵심가치: 신뢰성(신원·자격 검증), 합법성(법률준수·증거보전), 확장성(프랜차이즈·외국 진출), 수익성(서비스/구독/거래수수료).
본론 — 전체 기능 설계 (계층별로 정리)
A. 사용자 스펙 (주요 역할)
의뢰인(Client) — 일반 고객, 기업 고객(법무·HR 등)
조사원(Agent) — 정식 등록된 탐정/조사원(레벨·자격 표기)
관리자(Admin) — 플랫폼 운영자(콘텐츠, 결제, 컴플라이언스)
법률검토/고문(Legal) — 증거 적법성/리스크 자문
파트너(Partner) — 현지 조사 네트워크, 영상 분석업체 등
B. 핵심 모듈(기능별)
온보딩 및 신원·자격 검증
고객: 전화번호 인증(OTP), 이메일, 신분증 제출(이미지) → KYC(선택적)
조사원: 신원인증(주민등록/사업자), 자격증/경력 업로드, 신원검증(전자문서/대면심사), 계약서(전자서명)
레벨·평판 시스템: 평점, 수행이력, 신고내역(투명 표기)
의뢰 접수·매칭
의뢰 타입 분류: 실종/탐문·불륜·기업·배임·신원조회·현장감시 등
상세폼(증상/목표/예산/긴급도/지역/허가여부 체크)
자동 매칭 알고리즘: 지역·전문성·레벨·가용성 기반 매칭 + 조사원 제안 선택 가능
익명 의뢰 옵션(법적 한계 표기)
계약·결제·에스크로
표준 서비스 계약서 템플릿(의뢰 유형별) 자동 생성 — 전자서명 연동
선입금·에스크로(중간결제, 완료확인 후 잔금지급)
결제수단: 카드, 계좌이체, 법인청구서, 가상계좌, 외환결제(기업용)
영수증/세금계산서 발행 자동화
작업 관리(사건 워크플로우)
사건 타임라인(상태: 접수 → 착수 → 진행 → 완료 → 보고)
작업별 체크리스트(현장촬영, 인터뷰, 자료확보 등)
일정·위치 공유(조사원 위치 추적은 법적 동의가 있을 때만)
파일·증거 업로드(메타데이터 자동 기록: 촬영일시·GPS·디바이스 해시)
증거관리 & 보안
원본 보존: 업로드 시 무결성 해시(sha256) 자동 기록
타임스탬프·블록체인 해시 저장 옵션(증거 신뢰성 강화)
접근권한 제어(사건별 권한, 열람 로그)
암호화(서버·전송·백업 모두 암호화)
보고서·증거 패키지
표준 보고서 템플릿(PDF) 자동생성: 요약 → 세부사실 → 증거 첨부(미디어)
법정 제출용 포맷(요약본 + 원본링크 + 해시)
비디오/오디오 자동 트랜스크립션(검색 가능) 및 증거 인덱싱
커뮤니케이션
플랫폼 내 1:1 채팅(파일 전송, 이모지 금지)
실시간 화상회의(녹화·녹취, 법적 고지)
알림(이메일/카카오·문자·앱푸시) — 사용자가 원하는 채널로
결제·정산·수익모델
플랫폼 수수료(건당/구독) + 조사원 수수료(표준 계약)
프리미엄 구독: 기업 전용 리포팅·전담조사원·우선매칭
애드온: 법률자문, 현장촬영 드론, 디지털포렌식, 해외조사 네트워크 수수료
보험/환급연계(사건 무효 시 환불 정책 명확화)
규정준수·리스크 관리
한국 법률(사생활·통신비밀보호법·형사사법절차) 준수 체크리스트 내장
국제 MOU·현지법 가이드(해외조사시 필수 검토항목)
사건별 법률 검토 트리거(개인정보 침해 가능성 등)
내부 감사 로깅·컴플라이언스 대시보드
관리자 대시보드 & 리포팅
KPI: 사건 수, 성공률, 평균 처리건수, CS, 매출, 정산현황
안전 알람(문제사건/법적 분쟁/피해신고)
사용자·조사원 관리, 교육·인증 관리
AI·자동화 기능
사건 분류 자동화(NLP) — 의뢰자 입력으로 적정 조사프로토콜 추천
증거(이미지/영상) 자동 분석(얼굴·차량·로고 식별) — 법적 동의 필수
오디오 → 텍스트 전사, 핵심문장 추출, 타임코드 매핑
챗봇 상담(초기 상담, 견적 가이드라인) — 법적 고지 포함
외부 연동(플러그인)
결제 PG, 전자서명, SMS, 카카오톡 연동, 구글드라이브/S3 백업
법률 자문 API(내부 템플릿 / 외부 로펌)
외주현지 파트너 네트워크 관리용 API
C. 비기술 요소
정책·법률 체계
표준 이용약관, 개인정보처리방침, 증거보관정책(보관기간)

🧩 핵심 모듈 및 기능
A. 온보딩 및 인증

OTP/이메일 인증, 신분증 제출
조사원 자격증 업로드, 전자서명 계약
평판 시스템: 리뷰, 신고, 수행이력
B. 사건 접수 및 매칭
사건 유형 자동 분류 (NLP 기반)
지역·전문성·가용성 기반 AI 매칭
익명 의뢰 옵션 (법적 고지 포함)
C. 계약 및 결제
전자계약서 자동 생성 (DocuSign 연동)
에스크로 결제: 선입금 + 완료 후 정산
결제수단: 카드, 계좌, 법인청구, 외환
D. 조사 워크플로우
사건 타임라인: 접수 → 착수 → 진행 → 완료

위치 공유, 일정 관리, 증거 업로드

해시 기반 무결성 검증 (SHA-256)
블록체인 저장 옵션 (Hyperledger Fabric)

F. 보고서 자동화
템플릿 기반 보고서 생성 (PDF)
AI 요약 + 증거 첨부 + 전자서명
법정 제출용 포맷 자동 생성
G. 커뮤니케이션
1:1 채팅, 실시간 화상회의 (녹화/녹취)
알림: 이메일, 문자, 앱푸시, 카카오톡
H. 수익화 및 정산
플랫폼 수수료(10~30%), 조사원 수익 분배
프리미엄 구독: 기업용 리포팅, 전담팀
애드온: 법률자문, 드론촬영, 디지털포렌식
